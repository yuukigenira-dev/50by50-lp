# 50by50 Episode 0 — 動くプロトタイプ

## これは何
HTML/CSS/JSのみのブラウザノベルゲーム器(エンジン)。台詞はすべて【仮テキスト】。
index.htmlをブラウザで開くだけで動作。GitHub Pagesにそのまま置ける。

## 実装済み
- タイトル画面 / 本編 / エンド画面
- 立ち絵表示(透過済み): 泪通常・泪戦闘(可変バイオリン)・薫通常
- 表情アイコン14種(7表情×2人)をテキストウィンドウに表示
- 話者フォーカス(話していない側が沈む)
- タイプライター表示 / クリックで全文表示→次へ
- 選択肢分岐(任務/感情ルート→合流)
- **任務50:50感情ゲージ**: 選択でマーカーが移動、エンドで結果表示
- スマホ縦画面ファースト / キーボード操作対応

## シナリオの書き方(game.js冒頭のSCENARIO配列)
1ノード = 1画面。使えるキー:
- text: 本文(必須) / name: 話者名 / face: FACE('shade','angry')等
- l / r: 左右の立ち絵(SPRITES.shade等、nullで退場)
- focus: 'l'|'r' 話者側を明るく
- bg: 背景変更 / gauge: ±n でゲージ移動
- choices: [{label, gauge, goto}] / goto: idジャンプ / end: true
- 表情名: neutral, smirk, shaken, angry, anguish, tearful, combat
