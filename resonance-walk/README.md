# 50by50 Resonance Walk -星儀社観測記録- v1.4 Soundtrack

泪／SHADEを操作して5地点を歩き、観測記録（残響ログ）を拾う探索Webアプリ。
素のHTML/CSS/JS・ゼロ依存・ビルド不要・file://直開き対応（RHYTHM EP / Manga Prompt Builder と同じ運用形態）。

v1.2は、泪の公式透過スプライト（v1.1で統合）に加えて、広場・通路・屋上・星儀社メインフロアの
4地点の完成背景（1024×1536・縦2:3）を統合したSide-view版です。レゾナ調整室とタイトル背景は据え置き。
横スクロール型v1系の完成度を上げる更新であり、2.5D探索版は別系統として扱います。

## 素材差し替え
### 背景
`assets/bg/` に画像を置き、該当地点の `bg` を
`{ type:"image", src:"assets/bg/xxx.jpg", wash:0.15, deco:"plaza" }` に変更。
`wash` は白ウォッシュ量（0〜1、トーン統一用）。`deco` は近景装飾（手すり・譜面台影など）の種類で、画像化したら `deco` を外してもよい。

### 泪の公式スプライト（v1.1実装済み）
- `assets/sprites/rui_v1_1.png` … 2400×900の4ポーズアトラス
- `assets/sprites/rui_v1_1_frames.js` … 各コマの座標表
- `assets/sprites/rui_*_00.png` … 1コマ600×900・透明背景・足元中央アンカーの個別書き出し

アトラス内の並び：
```js
window.RW_ATLAS = { frames: {
  "rui_idle_00":    { x:0,    y:0, w:600, h:900 },
  "rui_walk_r_00":  { x:600,  y:0, w:600, h:900 },
  "rui_inspect_00": { x:1200, y:0, w:600, h:900 },
  "rui_react_00":   { x:1800, y:0, w:600, h:900 }
}};
```

左向きは描画時に右向きを水平反転します。1枚歩行のため、待機・歩行の微動はCanvas側で補っています。
アトラスの読み込みに失敗した場合は、従来のベクターシルエットへ自動的に戻ります。
